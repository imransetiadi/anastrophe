# Backend R1 Tracer Bullet — Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend Go yang menggantikan `scripts/anp1/lab_ca.py` untuk alur provisioning app: konfigurasi kanal, penerbitan `CredentialCert` yang lulus verifikasi lintas implementasi, dan penegakan batas 8 kartu per perangkat di PostgreSQL.

**Architecture:** Satu modul Go di `backend/` (ADR-0020) dengan `net/http` pustaka standar, paket `internal/*` per tanggung jawab, kripto dari pustaka standar (ECDSA P-256, HKDF, AES-GCM), CBOR/COSE minimal ditulis sendiri, dan PostgreSQL 16 lewat pgx. Penanda tangan Site CA berada di balik interface `certs.Signer` agar implementasi KMS/HSM bisa menggantikan kunci perangkat lunak tanpa mengubah pemanggil.

**Tech Stack:** Go 1.24+ (lokal 1.27.1), `net/http`, `crypto/*`, PostgreSQL 16 (lokal `postgresql@16`), `github.com/jackc/pgx/v5`.

**Spec:** [`docs/SDD.md`](../../SDD.md) §7.3 (CredentialCert), §8.1 (model data), §8.4.1 (enrolment), §8.5 (API), §15 (katalog error); [`docs/QA_SUITE.md`](../../QA_SUITE.md) (TC-ENR-11, TC-ENR-12, TC-PROTO-01); ADR-0014, ADR-0020.

## Di luar cakupan (rencana berikutnya)

Autentikasi (Sign in with Apple, OTP), App Attest, integrasi KMS/HSM nyata, enrolment kartu fisik dengan HMAC registri dan security code, sinkron reader (mTLS), audit hash-chain, portal admin, dan infrastruktur multi-region (IaC).

## Global Constraints

- Go 1.24+; modul `github.com/imransetiadi/anastrophe/backend`; hanya pustaka standar kecuali pgx untuk PostgreSQL.
- Error API memakai RFC 9457 (`application/problem+json`) dengan `type` = kode katalog SDD §15 (mis. `ENR-LIMIT`).
- JSON memakai kunci snake_case; `Data` = base64 standar; waktu = ISO 8601 UTC — identik dengan kontrak draf app (`ProvisionedCredential`, `RemoteConfig`).
- `CredentialCert` = COSE_Sign1 ES256 (tag 18) atas map CBOR berkunci integer `{1 cred_id, 2 site_id, 3 pubkey, 4 zones, 5 channel (1 N-HCE, 2 B, 3 N-SE), 6 not_before, 7 not_after}`, total ≤ 200 B (SDD §7.3). Masa berlaku default 7 hari (ADR-0010).
- Maksimal 8 card instance aktif per perangkat, ditegakkan di transaksi dengan `SELECT … FOR UPDATE` (SDD §8.1, FR-15).
- Identitas kartu fisik mentah dan kontak tidak disimpan atau di-log (CLAUDE.md aturan 6). Tidak ada secret di repo.
- Setiap task: `go test ./...` di `backend/` hijau; `go vet ./...` bersih.

## Review Focus

1. **Signature COSE format DER vs raw.** `ecdsa.SignASN1` menghasilkan DER, sedangkan COSE ES256 mewajibkan r‖s 64 B. Harapannya sertifikat dari Go diverifikasi oleh implementasi Python (`lab_ca.verify_certificate`) dan sebaliknya. Test: Task 3, `TestSertifikatLintasImplementasi`.
2. **Ketukan ganda provisioning.** Dua `POST …/credentials` dengan `Idempotency-Key` sama harus menghasilkan satu kredensial dan respons identik. Test: Task 5, `TestIdempotencyKeySama`.
3. **Race batas 8 kartu (TC-ENR-12).** Dua permintaan paralel saat perangkat sudah memegang 7 kartu: tepat satu berhasil. Test: Task 4, `TestRaceBatasDelapan`.
4. **Kunci publik tidak valid.** Titik bukan di kurva atau panjang salah harus ditolak dengan `ENR-INVALID-KEY` (400), bukan diterbitkan. Test: Task 5, `TestKunciPublikTidakValidDitolak`.
5. **Kebocoran detail internal di error.** Respons error tidak boleh memuat pesan error Go/SQL mentah. Test: Task 1, `TestErrorTidakMembocorkanDetail`.
