# Enrolment via Undangan — Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengelola gedung bisa membuat undangan sekali pakai, dan app bisa mendaftar dengan undangan itu tanpa kartu fisik (FR-12, FR-53).

**Architecture:** Migrasi `0009_invitations.sql`, fungsi store `CreateInvitation`/`(*Tx).StartInvitationEnrollment`, cabang `invitation` di handler `POST /v1/enrollments`, perintah `anastrophe-registry invite`, dan klien app (parser tautan, argumen lab, teks galat).

**Tech Stack:** Go 1.27, PostgreSQL 16 (pgx), Swift 6.

**Spec:** [`docs/superpowers/specs/2026-11-01-undangan-design.md`](../specs/2026-11-01-undangan-design.md); ADR-0033; FR-12, FR-53; SDD §5.6, §8.1, §8.2; QA TC-ENR-07, TC-ENR-08, TC-ADM-05.

## Global Constraints

- Token: 32 byte `crypto/rand`, base64url tanpa padding (43 karakter); disimpan sebagai SHA-256. Token mentah tidak pernah disimpan atau dicatat (CLAUDE.md aturan 6 untuk kartu dan kontak; token diperlakukan setara rahasia).
- Undangan tak dikenal, kedaluwarsa, dan terpakai → 404 `ENR-INVITATION-INVALID`, dengan body identik.
- Masa berlaku default 7 hari, 1–30 hari lewat CLI.
- Undangan → `PROVISIONING` (SDD §8.2); batas 8 kartu dan `ENR-DUPLICATE` tetap berlaku.
- `ANASTROPHE_REQUIRE_PG=1 go test ./...`, `go vet ./...`, `swift test`, dan suite simulator hijau.

## Review Focus

1. **Pemakaian bersamaan.** Dua perangkat memakai undangan yang sama serentak: tepat satu berhasil. Test: Task 1 `TestUndanganBersamaanSekaliPakai`.
2. **Respons identik.** Tak dikenal, kedaluwarsa, dan terpakai. Test: Task 2 `TestUndanganTidakBerlakuIdentik`.
3. **Token bocor.** Test: Task 1 `TestUndanganTanpaTokenMentah`, Task 2 `TestTokenUndanganTidakBocor`, Task 3 `TestInviteMencetakTokenSekali`.
4. **Zona fail-closed.** Test: Task 1 `TestZonaUndangan`.
5. **Kartu yang sudah dipegang perangkat lain.** Undangan tetap `PROVISIONING`; perangkat yang sama `ENR-DUPLICATE`. Test: Task 1 `TestUndanganUntukKartuTerpegang`.
