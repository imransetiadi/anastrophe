# ADR-0043 — Fokus berikutnya: alur Tambah Kartu produksi

- **Temuan:** build Release belum punya menu Tambah Kartu (hanya Lab DEBUG), jadi FR-05, FR-10, FR-11, FR-12, dan FR-13 di sisi app belum bisa dipakai pengguna nyata.
- **Bukti baru vs ADR-0042:** enrolment server tidak butuh akun; App Attest belum ditegakkan; jalur undangan dan pesan alasan bisa diuji di simulator.
- **Di luar unit:** App Attest (NFR-S03), anggota/security code, akun, perlindungan klaim.
